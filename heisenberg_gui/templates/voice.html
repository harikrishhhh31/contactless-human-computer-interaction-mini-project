Voice Commands

📁 Applications

open [app] Launch any application (e.g., "open notepad", "open chrome")
close [app] Exit a running application

🌐 Web & Search

search [query] Perform Google search
play [video] on youtube Play content on YouTube

🔧 System Control

minimize window Minimize the current window
maximize window Maximize the current window
switch window Toggle between active windows

🔊 Volume Control

louder / quieter Adjust system volume levels
volume mute Silence system audio
volume set [0-100] Set precise volume percentage

☀ Display Control

brightness up/down Adjust screen brightness levels

⌨ Dictation Mode

kc mode Enable voice-to-text typing mode
kc end Disable voice-to-text mode
💡
Usage Tips For best results, speak clearly into the microphone. An active internet connection is required for recognition. 🎤
